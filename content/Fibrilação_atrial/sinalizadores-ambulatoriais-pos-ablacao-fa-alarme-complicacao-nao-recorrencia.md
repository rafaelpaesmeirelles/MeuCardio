# Sinalizadores ambulatoriais pós-ablação de FA: alarme de complicação

Pergunta de **consultório / plantão telefônico** após ablação de FA: o sintoma é **complicação que exige PS agora**, ou **recorrência/blanking** que pode seguir via eletiva?

**Fora de escopo:** anticoagulação peri/pós-ablação (ver [#827](https://github.com/rafaelpaesmeirelles/MeuCardio/pull/827) e `fa-pos-ablacao-principios-de-anticoagulacao-de-retorno-esc-2024`); manejo de blanking/reablação — [`fluxograma-recorrencia-fa-pos-ablacao-manejo-blanking-reablacao`](fluxograma-recorrencia-fa-pos-ablacao-manejo-blanking-reablacao.md).

## Princípio

**Recorrência de FA no blanking ≠ fístula atrioesofágica, tamponamento tardio ou AVC.** ESC 2024 (PMID 39210723) discute segurança e complicações da ablação no contexto AF-CARE; no ambulatorial, o primeiro filtro é **sintoma de alarme estrutural/neurológico/infeccioso**, não o Holter de recorrência.

## Sinalizadores → PS / urgência agora

| Suspeita | Sinais típicos (não exaustivos) |
|---|---|
| Fístula atrioesofágica / lesão esofágica grave | Febre + dor torácica/epigástrica + déficit neurológico / sepse / hematêmese — **dias a semanas** pós-ablação |
| Tamponamento / derrame pericárdico tardio | Dispneia progressiva, hipotensão, tontura, atrito, sinais de baixo débito |
| Estenose de veia pulmonar | Dispneia progressiva, tosse, hemoptise, intolerância ao esforço **semanas–meses** após |
| AVC / AIT / embolia | Déficit focal, fala, visão, confusão súbita |
| Infecção / sepse / endocardite rara | Febre persistente, calafrios, mal-estar progressivo pós-procedimento |
| Lesão frênica com insuficiência respiratória | Dispneia intensa, ortopneia nova, hipoxemia |
| Sangramento maior / hematoma expansivo | Sinais de choque hipovolêmico, hematoma cervical/inguinal expansivo (acesso) |

**Conduta:** não “esperar o retorno de blanking”. Orientar PS; avisar o serviço de arritmia quando possível. **Não improvisar doses** nem suspender/reiniciar anticoagulação neste protocolo.

## Sem alarme de complicação → via de recorrência / blanking

Palpitação isolada, FA documentada sem instabilidade, sintomas leves de blanking → usar [`fluxograma-recorrencia-fa-pos-ablacao-manejo-blanking-reablacao`](fluxograma-recorrencia-fa-pos-ablacao-manejo-blanking-reablacao.md). Educar os alarmes da tabela acima.

## Checklist de 90 segundos

1. Febre + dor + neurológico / sepse pós-ablação? → **PS agora** (pensar fístula até prova em contrário).
2. Congestão aguda / hipotensão / tamponamento? → **PS**.
3. Déficit neurológico? → **via AVC**.
4. Só palpitação / FA no blanking, estável? → fluxo de **recorrência**, não este.
5. Pergunta de anticoagular ou dose? → **documento de anticoag**, não este.

## Armadilhas

Tratar febre pós-ablação como “virose do blanking”; atrasar PS por “complicação rara”; misturar recorrência eletiva com alarme estrutural; usar este texto para decidir anticoagulação.

## Limite da evidência

Incidência de complicações graves é baixa, mas o **custo de atraso** (especialmente fístula atrioesofágica) é alto. Este pacote só decide o **primeiro destino ambulatorial**, não o algoritmo diagnóstico hospitalar completo.
