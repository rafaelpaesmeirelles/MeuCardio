# Checklist ambulatorial: quando encaminhar para ferro endovenoso na IC

Cenário: retorno de **insuficiência cardíaca**. A pergunta é de **destino**: permanece no plano oral/rastreio, ou precisa de **centro/serviço de infusão** para ferro endovenoso?

Complementa: [`sinalizadores-ambulatoriais-deficiencia-de-ferro-na-ic-quando-escalar`](sinalizadores-ambulatoriais-deficiencia-de-ferro-na-ic-quando-escalar.md) · [`fluxograma-ambulatorial-deficiencia-de-ferro-destino`](fluxograma-ambulatorial-deficiencia-de-ferro-destino.md). Doses e critérios laboratoriais finos: [`fluxograma-deficiencia-de-ferro-na-insuficiencia-cardiaca-rastreio-e-reposicao-endovenosa-esc-2023`](fluxograma-deficiencia-de-ferro-na-insuficiencia-cardiaca-rastreio-e-reposicao-endovenosa-esc-2023.md).

## Encaminhar ferro EV / infusão agora (ambulatorial urgente em dias)

| Situação | Por quê |
|---|---|
| ICFEr ou ICFElr **sintomática** + deficiência de ferro pelos critérios ESC, **sem** ciclo EV planejado | Classe de recomendação 2023 para sintomas/QoL; evidência FAIR-HF/CONFIRM-HF |
| Alta recente por IC aguda + deficiência documentada e sem reposição peri-alta | Contexto AFFIRM-AHF — não diluir no retorno longo |
| Sintomas limitantes + deficiência + acesso a infusão | Destino operacional; não “aguentar até o próximo semestre” |
| Deficiência absoluta com anemia e pista de perda — **em paralelo** à investigação GI | Reposição não espera o colonoscópio se a indicação de EV já existe; investigação não é cancelada |

## Pode permanecer no ambulatório geral (com plano explícito)

1. Sem deficiência no rastreio recente — repetir periodicamente.
2. Já em janela pós-infusão aguardando reavaliação de ferritina/TSAT.
3. ICFEp ou assintomático — sem indicação ESC formal de EV para desfecho de IC; investigar causa.
4. Instabilidade / sangramento ativo — **não** é caminho de infusão eletiva; é **PS** (ver sinalizadores).

## Antes de encaminhar (checklist 60–90 s)

| Item | Feito? |
|---|---|
| FEVE / fenótipo (ICFEr vs ICFElr vs ICFEp) documentado | |
| Sintomas (NYHA) registrados | |
| Ferritina **e** saturação de transferrina recentes (não só Hb) | |
| Sangramento ativo / instabilidade excluídos (senão → PS) | |
| Lista de antitrombóticos / IBP / DRC anotada (pista de causa) | |
| Hipersensibilidade prévia a ferro EV perguntada | |
| Resumo escrito: “deficiência + sintoma + FEVE” para o serviço de infusão (**sem inventar mg neste doc**) | |

## O que não fazer no encaminhamento

- Substituir ferro EV por oral “enquanto espera” como se fosse equivalente (IRONOUT-HF).
- Encaminhar só porque a Hb está “um pouco baixa” sem ferritina/TSAT.
- Usar este checklist para protocolar ESA (eritropoiese) — ESC Classe III na anemia da IC sem outra indicação.
- Misturar com destino de congestão (#842) ou IC avançada (#878).

## Armadilhas

- Pedir só hemograma e chamar de “anemia da IC” sem ferro.
- Atrasar investigação de sangramento oculto sob AAS/DOAC/varfarina.
- Reexpor paciente com reação grave prévia sem estrutura de emergência.
- Prometer redução de mortalidade — os ensaios sustentam sintoma/hospitalização, não morte.

## Limite da evidência

Checklist operacional de **encaminhamento**. Cortes laboratoriais, formulação e miligramas permanecem no fluxograma ESC 2023 já revisado e nas bulas/instituição.
