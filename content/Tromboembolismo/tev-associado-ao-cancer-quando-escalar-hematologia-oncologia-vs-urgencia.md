# TEV associado ao câncer: quando escalar hematologia/oncologia versus urgência

Cenário: adulto com **câncer ativo** e TEV suspeito ou confirmado, **sem** alarme de TEP/instabilidade/isquemia/sangramento maior — gate já aplicado em [`sinalizadores-ambulatoriais-tev-associado-ao-cancer-destino-ps-vs-oncologia`](sinalizadores-ambulatoriais-tev-associado-ao-cancer-destino-ps-vs-oncologia.md).

ASH 2021 (PMID 33570602), ASCO 2023 (PMID 37075273) e ITAC 2022 (PMID 35772465) sustentam HBPM ou DOAC selecionado no CAT; o que este braço responde é **quem decide o quê no consultório**.

## Passo a passo

### 1. Confirmar que o gate de PS está negativo
Sem dispneia/dor torácica súbita, síncope, hipoxemia nova, hipotensão, flegmasia, sangramento maior. Se dúvida → PS (não este braço).

### 2. Gatilhos para hematologia / oncologia (ambulatorial ou retorno 24–72 h)

| Gatilho | Por quê articular |
|---|---|
| Trombocitopenia sem sangramento ativo | Ajuste de estratégia e risco; limiar/dose ficam em docs dedicados / equipe |
| Câncer GI/GU ou alto risco mucoso | ITAC/ASH: cautela com DOAC; decisão compartilhada |
| Interação forte com terapia sistêmica | Evitar troca improvisada isolada |
| Escolha DOAC vs HBPM ainda aberta | Ver [`fluxograma-doac-versus-dalteparina-no-tev-do-cancer`](fluxograma-doac-versus-dalteparina-no-tev-do-cancer.md) + oncologia |
| TEV incidental estável em estadiamento | Plano oncológico + anticoagulação; [`fluxograma-tev-incidental-em-exame-de-imagem`](fluxograma-tev-incidental-em-exame-de-imagem.md) |
| Fragilidade / metástase visceral / IRA | Rede e vigilância mais estreitas |

### 3. Ainda empurram internação / observação mesmo sem TEP óbvio

1. Rede insegura (sem fármaco, sem retorno, sem suporte).
2. Extensão ilíaco-femoral incapacitante / dúvida de flegmasia.
3. Recorrência sob anticoagulação plena → ambiente seguro + [`tev-recorrente-sob-anticoagulacao-em-dose-terapeutica-conduta`](tev-recorrente-sob-anticoagulacao-em-dose-terapeutica-conduta.md).
4. Trombocitopenia **com** sangramento ou TEV sintomático novo → PS/observação (não “só e-mail para oncologia”).
5. Gestação — via própria (não este protocolo).

### 4. Rede segura (obrigatória se liberar)

| Elemento | Exigência mínima |
|---|---|
| Acesso ao fármaco | Obtém a primeira dose nas próximas horas |
| Contato oncológico | Canal conhecido (equipe / plantão / retorno) |
| Retorno | 24–72 h se dúvida; ≤7 dias se estável com plano fechado |
| Orientação escrita | Mesmo checklist do protocolo irmão |

### 5. O que este doc **não** faz
Não escreve doses nem limiar plaquetário. Não reabre #837/#871. Não substitui os ensaios/escolha DOAC-HBPM nem a via de cardio-oncologia para TEP + trombocitopenia.

## Armadilhas

Chamar “só specialty” o paciente com dispneia súbita; liberar CAT sem fármaco; inventar dose; duplicar AVERT/CASSINI (profilaxia primária) neste hub de destino.

## Limite da evidência

Diretrizes CAT definem classes de opção terapêutica; o roteamento local (PS × specialty × retorno) é organizacional. O gate clínico (alarme × specialty × rede) é o conteúdo defensável deste braço.
