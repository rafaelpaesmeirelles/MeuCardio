# Pausa temporária dos aplicativos nativos — 03/09/2026

Decisão de produto registrada em 03/09/2026:

- por enquanto, o CorVIA não continuará desenvolvendo nem atualizando os aplicativos nativos para Android e Windows;
- a superfície prioritária é o CorVIA web/PWA;
- os botões públicos de download de Android e Windows devem permanecer removidos da tela de login;
- a opção pública final para novos usuários é **“Novo no CorVIA? / Solicite seu Acesso”**;
- artefatos, scripts e infraestrutura nativa existentes não são apagados neste lote: ficam congelados para eventual reativação futura mediante decisão explícita;
- nenhuma nova versão nativa deve ser promovida por iniciativa de desenvolvimento até que a pausa seja formalmente encerrada.

Este registro não altera autenticação, permissões, conteúdo científico, RAG, migrations ou banco de dados.
